Features

Script Manager
Save JavaScript snippets that auto-run on matching domains on every page load. Leave domain blank to run on every site. Supports wildcards like *.example.com.
Persistent Global Scripts
Scripts are stored in this page's localStorage. On every page you visit, devTools.js loads this page in a hidden iframe to fetch your scripts and run matching ones automatically.
Chii Debugger
Injects a remote DevTools inspector panel into any page. Press Ctrl+Shift+I to toggle it.
Bookmarklet Runner
Copy any javascript: URL then press Ctrl+V outside a text field to run it on the current page.
